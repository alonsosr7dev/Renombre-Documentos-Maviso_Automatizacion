# Renombre de Archivos Masivo

Herramienta gratuita desarrollada en Excel VBA para renombrar múltiples archivos de forma rápida y sencilla.

## 📌 ¿Qué hace?

Esta macro permite automatizar el renombrado masivo de archivos, evitando tener que cambiar el nombre de cada archivo manualmente.

## 🚀 Características

- Renombrado masivo de archivos.
- Automatización de una tarea repetitiva.
- Fácil de utilizar desde Excel.
- Ahorro de tiempo en procesos de gestión de archivos.

## 💻 Requisitos

- Microsoft Excel.
- Habilitar el uso de macros (VBA).

## 📥 Descarga

Descarga el archivo **Renombre Archivos Masivo.xlsm** desde este repositorio.

## ▶️ Uso

1. Descarga el archivo `.xlsm`.
2. Abre el archivo con Microsoft Excel.
3. Si Excel muestra una advertencia de seguridad, habilita las macros únicamente si confías en el archivo.
4. Sigue las instrucciones incluidas en la herramienta.Antes de dar click al boton se debe seleccionar toda la columna A
5. Selecciona los archivos que deseas procesar.
6. Ejecuta la macro para realizar el renombrado masivo.

## ⚠️ Recomendación

Antes de utilizar la herramienta con muchos archivos, se recomienda realizar una prueba con una copia de los archivos originales.
